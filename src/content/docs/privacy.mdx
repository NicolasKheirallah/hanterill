Hanterill is entirely local. It talks to the vehicle and writes to your disk. There is no backend and no account.

## Stays on your machine

- Every diagnostic session, DTC read and live capture (a durable local archive with your notes)
- Exports you create (JSON, CSV, ZIP bundles)
- Application settings, themes and connection profiles
- Logs
- Per-vehicle performance caches, stored under a hash of the VIN so file listings expose no identity

## Never collected

- No telemetry
- No analytics or usage tracking
- No cloud account
- No external backend
- No diagnostic data uploaded anywhere
- No third-party crash reporting

## VIN and coordinate redaction

The VIN is read during vehicle identification. In logs and exports, Hanterill redacts it where it
is not required, so a shared session file does not carry a full VIN by default. Full VIN is kept
only where you explicitly ask for it.

The same discipline covers position: pre-purchase inspection reports carry no GPS sections at all,
exportable coordinates are rounded to roughly 110 metres, and the support bundle scrubs
serial numbers, private addresses, credentials and decimal coordinates (`[REDACTED-GPS]`) before a
file leaves the machine, while keeping genuine diagnostic readings intact.

## Network activity

During a session, Hanterill communicates only with the vehicle over the local link. The application does not need an internet connection to run. This website separately queries the GitHub API to show the latest release and repository stats.

## No subscription

There is no paid tier and no license server. The source is available to read, and Hanterill is provided for personal, non-commercial use. There is nothing to monetise in your vehicle data.

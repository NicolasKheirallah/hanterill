Download Hanterill for your computer, check the file, then open the app before connecting a car.
The [download page](/download) shows the latest published release. Features described in an
unreleased changelog entry may not be in that download yet.

## Choose a file

| Computer | Choose | Before first launch |
| --- | --- | --- |
| Apple Silicon Mac | macOS arm64 `.dmg` | Drag the app to Applications. |
| Intel Mac | No macOS x86_64 build has been published yet; check the assets of the release you install | |
| Windows 10 or 11, x64 | Windows x64 setup `.exe` | The installer can fetch WebView2 if it is missing. |
| Windows ARM64 | Use an ARM64 artifact only if the release lists one | Check the release assets; do not assume every release publishes one. |
| Ubuntu or Debian | `.deb` | Install with your package manager so dependencies are resolved. |
| Fedora, openSUSE and other RPM distributions | `.rpm` | Install with your package manager. |
| Other Linux systems | The portable `.tar.gz` archive, or a package made for your distribution | WebKitGTK 4.1 is required. Check the asset list for the current release. |

The standalone Windows executable needs the Microsoft Edge WebView2 Evergreen Runtime already
installed. Package types vary by release; the assets on the release page are the source for the
version you download.

## Check the download

The release includes `SHA256SUMS.txt` when checksums are published. Compare the checksum of your
download with the entry for that exact filename. On macOS or Linux, run
`shasum -a 256 <downloaded-file>`. On Windows PowerShell, run
`Get-FileHash <downloaded-file> -Algorithm SHA256`. A mismatch means you should discard the file
and download it again.

## Open it on macOS

Open the app from Applications. If Gatekeeper says the developer cannot be verified, Control-click
`Hanterill.app`, choose **Open**, then confirm **Open**. The macOS build is ad-hoc signed and is not
notarized with an Apple Developer ID. On the first vehicle connection, allow the local-network
permission. You can review it later under **System Settings → Privacy & Security → Local Network**.

## Open it on Windows

Run the setup file. SmartScreen may show **Windows protected your PC** for an unsigned build. After
checking the release source and checksum, choose **More info → Run anyway** if you want to proceed.
If the app window does not open, check that WebView2 is installed. When Windows Firewall asks,
allow Hanterill to use the network needed for the vehicle connection.

## Open it on Linux

On Ubuntu or Debian, install a downloaded package with `sudo apt install ./<package>.deb`.
Hanterill's vehicle connection uses ordinary UDP and TCP sockets, so the app itself does not need
root privileges. If a portable build does not open, check for WebKitGTK 4.1 and the dependencies
listed with that release. The [Connection](/docs/connection) guide covers a link-local adapter
that appears in Linux but cannot reach the car.

## After installation

The released app needs a real vehicle for a diagnostic session. The browser's
[simulated scan](/features/vehicle-diagnostics) lets you see the flow without one; development
builds have a separate simulated vehicle harness. Before buying a cable, check
[Supported vehicles](/docs/supported-vehicles) and [Hardware and adapters](/docs/hardware-and-adapters).
Then follow [Getting started](/docs/getting-started).

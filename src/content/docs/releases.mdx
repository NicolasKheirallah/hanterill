Versions use three parts: major, minor and patch. Every release corresponds to a tagged version, and
the release notes for each version are published on the [changelog page](/changelog).

## Where to find downloads and release notes

- **[Changelog](/changelog)**: Detailed release notes for every tagged version, rendered on this site.
- **[Download](/download)**: Current installers for macOS, Windows and Linux.

## How release notes describe platform maturity

Release notes use the same transparent support levels as the rest of the documentation:

1. **Verified**: Features and readings confirmed on live vehicles (CMA electric vehicles today).
2. **Provisional / Testing**: Catalogued modules, readings, and battery layouts for SPA and SEA1 vehicles that are wired into the app and undergoing wider live-vehicle verification.
3. **Research**: Newly catalogued identifiers, bus captures, and ongoing protocol documentation.

## Installers and checksum verification

Each release publishes native desktop installers for macOS, Windows, and Linux. See
[Install on your computer](/docs/installation) for platform-specific steps. When a release includes
`SHA256SUMS.txt`, you can compare the SHA-256 checksum of your downloaded installer before opening
it.

<Callout kind="caution" title="First-launch prompts on macOS and Windows">
macOS builds use ad-hoc signing, so macOS Gatekeeper requires a right-click and Open (or a one-time
quarantine attribute clear) on first launch. Windows SmartScreen may also show an unknown-publisher
prompt on first launch. Compare the SHA-256 checksum against `SHA256SUMS.txt` to verify your
download.
</Callout>

## Updating Hanterill

Because the Hanterill desktop application makes zero internet connections, it never downloads or
installs updates in the background. To update to a newer version, download the latest installer from
the [download page](/download)
and install it over your existing copy.

Your saved sessions, captures, and settings remain intact across updates: the local session archive
is versioned so older sessions continue to open cleanly in newer releases.

## Check a used electric car

1. Connect and read the vehicle identity and fault codes. Check which control units answered.
2. Open **Battery Health**. Read the car's reported SoH and SoC, then open the **Cell Map** if cell readings are available. Compare cell voltage spread only with readings taken under similar conditions.
3. Open the **Inspection Report** and read its findings and coverage gaps. A missing battery or fault reading is not a pass.
4. Save the session yourself so you can return to the captured evidence later. Choose VIN masking before sharing a PDF.

## Investigate a warning

1. Open **Fault Codes** and scan. Start with active and pending codes, then include stored codes if you need the history.
2. Select a code to see which unit reported it and whether it supplied a snapshot of the conditions at the time. The available snapshot fields vary.
3. Record the result before repairing anything. A code indicates where to investigate; it does not identify the failed part by itself.

## Verify a repair

1. Save a scan before the repair. After the repair, scan again and compare the results from the same car.
2. Clear fault codes only if the installed app supports write actions and you intend to change the car's fault memory. Review the backup and verification options before confirming.
3. Read the result for each unit and scan again. A code that returns needs further investigation.

## Check a software update

1. Run **Firmware Audit** before the update and save its results.
2. Repeat the audit afterward. Compare only version fields that were actually read on both visits.
3. A changed version shows what the unit reports now. An unchanged or missing version does not prove exactly what the workshop did.

## Investigate 12 V drain

1. After the car has been parked, open **12 V Sleep Drain** and read the average current and sample distribution.
2. Check whether the app marks the readings as consistent. Higher-current samples suggest more time awake or drawing power, but do not identify the cause.
3. Check 12 V battery condition separately and compare readings under similar conditions. The drain screen has no wake-cause log.

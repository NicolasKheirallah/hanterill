Hanterill is a desktop application. It runs on your computer and talks to the vehicle over Ethernet. There is no account to create and no server to reach.

## Before you start

You need:

- A supported vehicle. Polestar 2 and the CMA Volvos (XC40/EX40, C40/EC40) are the tested platforms. See [Supported vehicles](/docs/supported-vehicles).
- A passive ENET cable (OBD-II to RJ45).
- An Ethernet interface on your computer. A USB-C to Ethernet adapter is fine.
- Hanterill installed. See [Download](/download).

## First session

1. Turn the vehicle to ignition-on. You do not need to start it.
2. Connect the ENET cable to the OBD-II port and the RJ45 end to your Ethernet interface.
3. Open Hanterill. It looks for a vehicle on the link and shows a connection state in the title bar.
4. When the state reads **Connected**, open **Overview**. Hanterill reads vehicle identification and a battery summary in one pass.
5. Open **Fault codes** to run a scan, **Battery** for the full high-voltage view, or **Report** for the scored inspection.
6. Sessions you open are archived locally as you go; the Sessions page reopens them later and compares any two.

Everything so far is read-only, and in released builds it stays that way: the operations that
change the vehicle are compiled out. See [Safety](/docs/safety).

## No car attached?

The connection page includes deterministic simulation vehicles (healthy baseline, fault-injected,
sleep-drain), so every screen can be exercised offline before you plug in. Simulated sessions are
labelled as simulated throughout.

## Where data goes

Sessions, reads and exports are written to your disk. Hanterill does not upload anything. See [Privacy](/docs/privacy).

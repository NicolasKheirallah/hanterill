openCMA is built CMA-first. The Compact Modular Architecture platform under Polestar 2 and the smaller electric Volvos is where battery, ECU and routine coverage was written and validated.

## Platform compatibility is not support

Two different things:

- **Platform compatibility** means openCMA can reach the vehicle over DoIP.
- **Verified support** means the diagnostic functions are implemented and checked
  against known-good references.

A car can be reachable and still expose almost nothing useful. Status labels on
this site always reflect verified support.

## Status labels

| Label | Meaning |
| --- | --- |
| Supported | Verified runtime implementation. Battery, DTC, ECU identification and live data are exercised regularly. |
| Partial | Some functions verified, others not yet covered on this vehicle. |
| Testing | Implementation exists but needs validation. |
| WIP | Actively being developed. Connects, but decoding is incomplete. |
| Research | Architecture being investigated. Not usable for diagnostics. |
| Planned | On the roadmap. No implementation yet. |

**Vehicle Configuration** reads the option information the car makes available. It can help you understand which features the current configuration reports, but it is not a complete factory build certificate or proof that a part was fitted after delivery.

## Read the option map

The screen reads an option map from the car and shows entries it can name. You can search by feature, filter by category or view entries that appear present, absent or supported but not fitted. An entry without a verified name remains identified by its position rather than being assigned a guessed feature.

Some additional configuration records are retained as evidence even when the app cannot decode their meaning. A record existing in the car does not mean Hanterill can extract paint, upholstery, original packages or a complete change history from it.

## Check a possible retrofit

The app offers a retrofit compatibility check. It compares the evidence it has for a selected feature and may report that hardware is missing or the current configuration does not match; treat that result as guidance about the available readings, because it cannot prove when a feature was installed or whether a workshop performed an authorised upgrade.

You can download a configuration report for your records; review vehicle identifiers and undecoded entries before sharing it. Reading the map does not change the car's configuration.

openCMA is **source-available for private use**. The `LICENSE` file in the
repository is the authoritative text; this page is the plain-language summary.

## What this means

- The source code is published and can be read, audited and built.
- You may use openCMA for personal, non-commercial diagnostics on vehicles you
  own or are authorised to work on.
- Commercial use, resale, or offering openCMA as a paid service is not permitted
  under the project license.
- It is **not** released under an OSI-approved open-source license. "Source
  available" and "open source" are not the same thing, and this site uses the
  accurate term.

## Why source-available

The project publishes its code so that owners and independent workshops can
verify exactly what openCMA sends to a vehicle, and so that protocol and decoder
work can be contributed back. Keeping it non-commercial keeps the focus on that
goal rather than on a product.

## Contributions

Contributions are accepted under the same terms. Protocol traces (VIN removed),
ECU maps and decoder corrections are the most useful. See
[Development](/docs/development).

## Authoritative text

Always defer to the `LICENSE` file in the repository. If anything on this site
conflicts with it, the `LICENSE` file wins.

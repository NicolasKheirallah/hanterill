I **Inställningar** kan du byta språk, färgtema, måttenheter och hur mycket information som visas. Appen sparar dina val på datorn.

## Språk

Hanterills gränssnitt finns på engelska, svenska, norska (bokmål), danska, finska, isländska, tyska och förenklad kinesiska. Du kan byta språk i **Inställningar** utan att starta om appen.

Vissa förkortningar, till exempel VIN för chassinummer, ser likadana ut på alla språk. [Ordlistan](/docs/glossary) förklarar dem.

## Färgteman

Du kan välja mellan åtta teman eller låta appen följa datorns ljusa och mörka läge:

| Tema | När det kan passa |
| --- | --- |
| **Neutral Light** | En ljus vy för vardaglig användning. |
| **Neutral Dark** | En mörk vy när du vill minska bländning. |
| **Protokoll Light** | Tydlig kontrast i dagsljus eller stark verkstadsbelysning. |
| **Protokoll Dark** | Mörk vy med tydliga markeringar i svag belysning. |
| **Polestar Light** | Ljus vy med återhållna färger. |
| **Polestar Dark** | Mörk vy med tydlig text och statusfärger. |
| **Nord** | Dämpade blågrå toner. |
| **High Contrast** | Extra tydliga gränser och statusmarkeringar. |

Välj det tema som är lättast för dig att läsa där du använder datorn. Inställningen påverkar inte bilens data.

## Användarlägen och täthet

**Ägare** visar översikter och vanliga kontroller. **Tekniker** visar fler feluppgifter, delsystem och serviceåtgärder. **Engineer** visar mer detaljerad diagnostik och verktyg för den som undersöker råa svar. Du kan byta läge utan att göra en ny skanning.

Med inställningen **Comfortable** får rader och knappar mer utrymme. **Compact** visar fler rader samtidigt på en mindre skärm.

## Tangentbord

Du kan nå kontroller med Tab och aktivera dem med Enter eller blanksteg. Escape stänger en öppen dialogruta. Använd **Cmd+K** på Mac eller **Ctrl+K** på Windows och Linux för att öppna kommandopaletten och söka efter en vy.

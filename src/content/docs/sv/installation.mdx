Hanterill är en datorapp för Windows, macOS och Linux. Den körs på din dator. Du behöver inget konto eller internet för att använda den med ett fordon.

## Välj rätt nedladdning

Öppna [nedladdningssidan](/download) och välj filen som passar din dator:

| Dator | Fil att välja | Så gör du |
| --- | --- | --- |
| Windows | Installationsprogram eller MSI | Öppna filen och följ anvisningarna. |
| macOS | DMG för Apple Silicon eller Intel | Öppna filen och dra Hanterill till Program. |
| Linux | DEB, RPM, AppImage eller arkiv | Välj det format du brukar använda för appar i din distribution. |

Om du inte vet vilken processor din Mac har, öppna **Om den här datorn** från Apple-menyn. Välj nedladdningen som motsvarar informationen om chip eller processor.

## Öppna appen första gången

Datorn kan be dig godkänna en app som laddats ned från internet. Kontrollera att det är den Hanterill-fil du tänkte installera innan du fortsätter.

### macOS

Öppna **Program** och starta Hanterill. Om macOS stoppar appen, öppna **Systeminställningar**, gå till **Integritet och säkerhet** och använd alternativet för att öppna Hanterill vid varningen. När Hanterill ber om tillåtelse att hitta enheter på det lokala nätverket, godkänn det så att appen kan nå fordonet via Ethernet-kabeln.

### Windows

Öppna Hanterill från Start-menyn efter installationen. Windows kan visa en säkerhetsfråga första gången. Kontrollera appens namn och välj att fortsätta om det stämmer med din nedladdning. När du söker efter ett fordon kan Windows-brandväggen fråga om Hanterill får använda det lokala nätverket. Tillåt åtkomst för nätverket som din kabelanslutna adapter använder.

### Linux

Installera paketet som passar din distribution och öppna sedan Hanterill från programmenyn. En AppImage är en portabel fil. Filhanteraren kan be dig göra den körbar innan den öppnas.

## Kontrollera installationen

Öppna vyn **Anslutning**. Du kan välja ett inbyggt simulerat fordon och utforska appen innan du kopplar in en riktig bil. Simulerade värden är märkta så att de inte förväxlas med fordonsavläsningar.

När du vill ansluta en bil, följ [Kom igång](/docs/getting-started). Om bilen inte visas, läs [Felsökning](/docs/troubleshooting).

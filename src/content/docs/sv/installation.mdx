Hanterill är en datorapp för Windows, macOS och Linux. Den körs på din dator. Du behöver inget konto eller internet för att använda den med ett fordon.

## Välj rätt nedladdning

Öppna [nedladdningssidan](/download) och välj filen som passar din dator:

| Dator | Fil att välja | Så gör du |
| --- | --- | --- |
| Windows | Installationsprogram eller MSI | Öppna filen och följ anvisningarna. |
| macOS | DMG för Apple Silicon eller Intel | Öppna filen och dra Hanterill till Program. |
| Linux | DEB, RPM, AppImage eller arkiv | Välj det format du brukar använda för appar i din distribution. |

Om du inte vet vilken processor din Mac har, öppna **Om den här datorn** från Apple-menyn. Välj nedladdningen som motsvarar informationen om chip eller processor.

## Öppna appen första gången

Datorn kan be dig godkänna en app som laddats ned från internet. Kontrollera att det är den Hanterill-fil du tänkte installera innan du fortsätter.

### macOS

Öppna **Program** och starta Hanterill. Om macOS stoppar appen, öppna **Systeminställningar**, gå till **Integritet och säkerhet** och använd alternativet för att öppna Hanterill vid varningen. När Hanterill ber om tillåtelse att hitta enheter på det lokala nätverket, godkänn det så att appen kan nå fordonet via Ethernet-kabeln.

### Windows

Öppna Hanterill från Start-menyn efter installationen. Windows kan visa en säkerhetsfråga första gången. Kontrollera appens namn och välj att fortsätta om det stämmer med din nedladdning. När du söker efter ett fordon kan Windows-brandväggen fråga om Hanterill får använda det lokala nätverket. Tillåt åtkomst för nätverket som din kabelanslutna adapter använder.

### Linux

Installera paketet som passar din distribution och öppna sedan Hanterill från programmenyn. En AppImage är en portabel fil. Filhanteraren kan be dig göra den körbar innan den öppnas.

## Linux: ställ in Ethernet-adressen

Hanterill behöver en IPv4-adress i intervallet `169.254.x.x` på din trådbundna adapter. På Ubuntu och andra Linux-system kan du behöva ställa in detta själv, även om kabeln är ansluten och länklampan blinkar.

Om Hanterill bara visar `lo` / `127.0.0.1` ser du datorns interna loopback-gränssnitt. Kontrollera den trådbundna adapterns adress med stegen nedan.

### 1. Hitta den trådbundna adaptern och kontrollera adressen

Anslut kabeln, väck fordonet och öppna en terminal:

```bash
ip -br link
```

Leta efter den trådbundna adaptern, som ofta heter `enx…`, `enp…` eller `eth0`. Kommandona nedan använder `enx00e04c681f03` som exempel. Byt ut namnet mot din egen adapters namn varje gång. Använd inte `lo` eller Wi-Fi-gränssnittet.

```bash
ip -4 addr show dev enx00e04c681f03
```

Leta efter en rad med `inet 169.254.../16`. Om den redan finns, välj adaptern i Hanterill och starta sökningen efter fordon. Om IPv4-adress saknas, använd ett av alternativen nedan. Om länken visar `NO-CARRIER`, kontrollera kabeln och väck fordonet först.

### 2. Spara inställningen med NetworkManager

Kommandona gäller system som hanteras av NetworkManager, bland annat många Ubuntu-installationer för datorer. Hitta anslutningsprofilen för din trådbundna adapter:

```bash
nmcli -f NAME,DEVICE connection show
```

Profilnamnet och adapternamnet är olika saker. Byt ut `Wired connection 1` nedan mot profilnamnet i kolumnen `NAME` för din trådbundna adapter:

```bash
nmcli connection modify "Wired connection 1" ipv4.method link-local ipv6.method link-local
nmcli connection up "Wired connection 1"
```

Om NetworkManager säger att behörighet saknas, kör kommandot igen med `sudo`. Om `nmcli` saknas eller NetworkManager inte körs, välj IPv4 **endast länk-lokal** i distributionens nätverksinställningar eller använd det tillfälliga alternativet nedan.

Inställningen sparas i profilen för kommande fordonsanslutningar. Om du även använder profilen för hem- eller kontorsnätverket, anteckna de ursprungliga inställningarna innan du ändrar dem och återställ dem efteråt. Om både IPv4 och IPv6 tidigare använde automatisk adresstilldelning återställer du dem med:

```bash
nmcli connection modify "Wired connection 1" ipv4.method auto ipv6.method auto
nmcli connection up "Wired connection 1"
```

### Alternativ: lägg till en adress för ett test

För att testa anslutningen utan att ändra en sparad profil kan du lägga till en tillfällig adress:

```bash
sudo ip addr add 169.254.10.10/16 dev enx00e04c681f03
```

Använd detta enbart på adaptern som är direkt ansluten till fordonet, och bara om adressen inte redan används på länken. Adressen sparas inte efter omstart, och nätverkshanteraren kan ta bort den vid återanslutning. Du kan själv ta bort den med:

```bash
sudo ip addr del 169.254.10.10/16 dev enx00e04c681f03
```

### 3. Kontrollera och anslut

Kör `ip -4 addr show dev enx00e04c681f03` igen och kontrollera att en rad med `inet 169.254.../16` visas. Gå tillbaka till **Anslutning** i Hanterill, uppdatera adapterlistan vid behov, välj den trådbundna adaptern och starta sökningen efter fordon.

Om adressen finns men fordonet ändå inte svarar, fortsätt med [Felsökning](/docs/troubleshooting). Inställningen ger datorn en lämplig nätverksadress. Se [Fordon som stöds](/docs/supported-vehicles) för vad Hanterill kan läsa från din modell.

Inställningarna beskrivs i [NetworkManagers IPv4-referens](https://networkmanager.dev/docs/api/latest/settings-ipv4.html) och [manualen för nmcli](https://networkmanager.dev/docs/api/latest/nmcli.html).

## Kontrollera installationen

Öppna vyn **Anslutning**. Även utan bil inkopplad ska du se datorns trådbundna Ethernet-adaptrar
listade med en bedömning i klarspråk för varje adapter (Wi-Fi och virtuella adaptrar filtreras
bort) och en status i stil med **Länk nere** så länge inget är kopplat till kabeln. Det betyder att
appen är korrekt installerad och ser din nätverksmaskinvara.

När du vill ansluta en bil, följ [Kom igång](/docs/getting-started). Om bilen inte visas, läs [Felsökning](/docs/troubleshooting).
